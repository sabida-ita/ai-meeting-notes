# 회의노트 정리 (AI Meeting Notes)

회의 중 적어 둔 메모를 붙여넣으면 **핵심 요약 · 결정 사항 · 할 일 · 논의된 문제**로 나눠 정리해 주는 웹 화면입니다.

## 실행 방법

별도 설치나 빌드가 필요 없습니다. `index.html` 파일을 브라우저로 열면 됩니다.

```
open index.html
```

## 구성

- `index.html` — HTML, CSS, JavaScript가 모두 들어 있는 단일 파일입니다. 외부 라이브러리를 쓰지 않습니다(웹폰트만 Google Fonts에서 불러오며, 연결이 없으면 시스템 서체로 대체됩니다).

## 현재 동작 방식

아직 AI 모델을 호출하지 않는 데모입니다. 입력한 글을 문장 단위로 나눈 뒤 신호어를 기준으로 네 갈래로 분류합니다.

| 분류 | 기준이 되는 표현 |
| --- | --- |
| 결정 사항 | 결정, 합의, 확정, 하기로, 미루기로 … |
| 할 일 | 준비, 공유, 전달, 검토, ~까지, 담당 … |
| 논의된 문제 | 문제, 이슈, 지연, 리스크, 부족 … |
| 핵심 요약 | 위 어디에도 걸리지 않은 앞부분 문장 |

정리는 브라우저 안에서만 이루어지며, 입력한 내용은 외부로 전송되지 않습니다.

## 실제 모델 연결하기

`index.html` 안의 `organize()` 함수가 정리를 담당합니다. 이 함수를 API 호출로 바꾸면 실제 모델을 붙일 수 있습니다. 이때 API 키는 브라우저 코드에 두면 노출되므로, 키를 보관할 서버(예: Vercel Functions)를 거치도록 해야 합니다.
